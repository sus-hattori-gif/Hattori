# Hattori

Hattori is a modular Python-based multi-tool for networking, OSINT,
encoding, hashing, and other security-related utilities.

The project is designed to provide multiple useful tools through a
single command-line interface while keeping each tool separated and
easy to maintain.

---

## Features

Hattori currently provides the following tools:

| # | Tool | Description |
|---|------|-------------|
| 1 | Hash | Generate hashes from text using supported hashing algorithms. |
| 2 | IP Finder | Retrieve IP address information. |
| 3 | Password Generator | Generate random passwords with configurable character sets. |
| 4 | Base64 | Encode and decode Base64 data. |
| 5 | DNS Lookup | Resolve domain names and retrieve their IP information. |
| 6 | Ping | Test host connectivity and measure response time. |
| 7 | Port Scanner | Scan TCP ports and identify accessible services. |
| 8 | Banner Grabber | Connect to network services and retrieve available banners. |
| 9 | WHOIS Lookup | Retrieve WHOIS information for domains. |
| 10 | IP Geolocation | Retrieve geographical and network information associated with an IP address. |
| 11 | HTTP Headers Analyzer | Retrieve and analyze HTTP response headers. |
| 12 | DNS Record Enumerator | Retrieve common DNS records such as A, AAAA, MX, NS, CNAME and TXT. |

---

## Output Manager

Hattori includes a centralized Output Manager for handling results
generated by its tools.

Instead of requiring every tool to implement its own file-management
system, tool output can be handled through a central system.

The Output Manager provides functionality for:

- Saving tool results
- Viewing saved outputs
- Searching saved outputs
- Deleting outputs
- Renaming outputs
- Exporting outputs

Saved results are stored in the `outputs/` directory.

### Directory Description

#### `core/`

Contains the main components of Hattori, including:

- Menu system
- Help system
- Banner
- Output Manager

#### `tools/`

Contains the individual Hattori tools.

Each tool is maintained as a separate Python module to make the project
easier to develop, debug, and extend.

#### `integrations/`

Contains integrations with external programs and projects.

This directory is intended for tools that Hattori communicates with
rather than implementing directly inside the main codebase.

#### `utils/`

Contains shared helper functions used by different parts of the project.

#### `outputs/`

Directory used by the Output Manager for storing generated results.

## Installation

### Requirements

- Python 3.x
- pip

Install the required Python packages with:

```bash
pip install -r requirements.txt
```

---

## Running Hattori

Run the main program with:

```bash
python main.py
```

Hattori will start its command-line interface.

From the main menu you can access:

```text
M / Menu
H / Help
O / Output
E / Exit
```

---

## Adding New Tools

Hattori is designed to be modular.

New tools should be added as separate modules inside:

```text
tools/
```

This keeps the main application and existing tools from becoming
unnecessarily large.

When adding a new tool, it should also be connected to the Hattori menu
and, where appropriate, the centralized Output Manager.

---

## External Integrations

Hattori is designed to support integrations with external security and
OSINT tools.

The `integrations/` directory is reserved for these integrations.

An example integration currently exists for the planned Sherlock
integration:

```text
integrations/
└── sherlock.py
```

The Sherlock integration is currently a placeholder and is not yet
configured as a fully functional bundled component.
